# Screenshots

This folder contains screenshots of the ZeroRAG application for documentation purposes.

## Recommended Screenshots to Add

1. **main_interface.png** - Main chat interface showing the Q&A functionality
2. **document_upload.png** - Document upload dialog
3. **search_results.png** - Search results with source citations
4. **health_dashboard.png** - System health monitoring page
5. **api_docs.png** - FastAPI auto-generated documentation (http://localhost:8000/docs)

## How to Take Screenshots

1. Start the application: `python start_app.py`
2. Navigate to http://localhost:8501 for the UI
3. Navigate to http://localhost:8000/docs for the API docs
4. Take screenshots showing key features
5. Save them in this folder with descriptive names
6. Update the main README.md to reference these screenshots

## Image Guidelines

- Use PNG format for best quality
- Recommended resolution: 1920x1080 or scaled down to 1280x720
- Show real data/examples that demonstrate the features
- Keep sensitive information out of screenshots
